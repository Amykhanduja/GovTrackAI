# GovTrack AI - User Guide
## Getting Started
Run the interactive wizard using `./govtrack setup`.

## Using the Dashboard
Access the dashboard at `http://127.0.0.1:8000`.
- **Dashboard**: View high-level KPIs and urgent deadlines.
- **Job Browser**: Semantic search over all processed opportunities.
- **Profile**: Customize your Target Roles and Education to let the AI calculate Eligibility.
